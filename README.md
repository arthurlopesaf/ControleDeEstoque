# Sistema de Gerenciamento de Estoque

## Descrição

Aplicação desenvolvida em JavaFX para gerenciamento de produtos de estoque.

O sistema permite cadastrar, visualizar, pesquisar, atualizar e excluir produtos utilizando conceitos de Programação Orientada a Objetos.

## Tecnologias

- Java
- JavaFX
- Scene Builder
- Git/GitHub

## Funcionalidades

- Cadastro de produtos
- Listagem em TableView
- Atualização de produtos
- Exclusão de produtos
- Pesquisa por nome, código ou categoria
- Cálculo do valor em estoque

## Conceitos Aplicados

- Classes e objetos
- Encapsulamento
- Construtores
- Métodos
- Coleções

## Como executar

1. Abrir o projeto na IDE.
2. Configurar o JavaFX.
3. Executar a classe Main.java.
